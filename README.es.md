## 🧭 Sobre mí

<br />

Construyo software práctico alrededor de **IA local**, **sistemas de agentes**, **automatización**, **ingeniería de juegos** e **infraestructura de producción**.

Mi trabajo se centra en sistemas que se pueden desplegar, probar, auditar y mejorar con el tiempo: agentes especializados, tooling LLM local, automatización con navegadores, plataformas multiplayer, juegos tácticos, dashboards, CLIs y productos web en producción.

> Entreno adaptadores LLM personalizados en GPUs de consumo, despliego juegos multiplayer en VPS de producción, y construyo sistemas de orquestación de agentes que funcionan sin dependencias cloud. Todo lo que construyo es open-source y local-first por diseño.

<br />

### Áreas de enfoque

<br />

| Área | Dirección |
|:---|:---|
| **🧠 IA Local** | LLMs en GPUs de consumo, GGUF, llama.cpp, CUDA, APIs locales compatibles con OpenAI. |
| **🤖 Agentes** | Identidades, skills, exportaciones, quality gates, flujos de trabajo y archivos por herramienta. |
| **🌐 Productos** | Plataformas SaaS, autenticación, pagos, dashboards, documentación, health checks y releases. |
| **🎮 Juegos** | Mundos multiplayer, mecánicas modulares, combate determinista, interacción en tiempo real e interfaces 3D. |
| **⚙️ Automatización** | Agentes de navegador, workflows de código, scripts de validación, chequeos de infraestructura. |

<br />

### Principios

<br />

| Principio | Significado |
|:---|:---|
| **Auditar primero** | Inspeccionar el estado real antes de tocar código o infraestructura. |
| **Cambios pequeños** | Preferir cambios enfocados que se puedan probar y revertir. |
| **Local-first** | La IA debe correr en hardware que la gente ya tiene. |
| **Disciplina de producción** | Logs, smoke tests, health checks y notas de rollback importan. |
| **Sin claims falsos** | Lo experimental va etiquetado como experimental. Lo de producción debe estar validado. |

## ⚙️ Cómo Trabajo

<br />

| Paso | Propósito |
|:---|:---|
| **01 · Auditar** | Inspeccionar el estado real antes de asumir el problema. |
| **02 · Acotar** | Definir el cambio más pequeño posible con un camino claro de rollback. |
| **03 · Implementar** | Hacer cambios enfocados con radio de impacto limitado. |
| **04 · Validar** | Ejecutar lint, type checks, tests, builds y smoke checks. |
| **05 · Documentar** | Registrar qué cambió, por qué cambió y cómo se revierte. |
| **06 · Publicar** | Desplegar con versionado alineado, health checks y verificación post-deploy. |

## 🔮 Filosofía

<br />

| Principio | Significado |
|:---|:---|
| 🖥️ **Local-first** | La IA corre en tu hardware. Sin cloud lock-in, sin suscripciones. |
| 🔒 **Privacidad por defecto** | Sin telemetría, sin fugas de datos, sin API keys para uso local. |
| 🔓 **Open-source siempre** | Todo lo que publico es abierto. Fórkealo, apréndelo, mejóralo. |
| 🎮 **Hardware de consumo** | Entrenando LLMs en una GTX 1060. Si necesita una H100, el diseño está mal. |
| 🚢 **Productos reales** | Apps funcionando en producción > presentaciones pulidas. |
