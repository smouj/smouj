## / Perfil

Construyo herramientas para el ordenador que tienes delante: runtimes de IA local, utilidades de Windows, herramientas para desarrolladores y juegos pequeños.

Casi todo parte de la misma restricción: tiene que funcionar offline, en hardware que la gente ya tiene, sin un servidor en la ruta crítica.

> **Ahora** — Construyendo **Adobado Kit**, **Kimari**, **Latido** y **Voryda**; investigando sistemas de juego en Godot.

## / Práctica

| Principio | En la práctica |
|:--|:--|
| **Medir antes de reescribir** | Perfila lo real primero. Después cambia la pieza más pequeña que explique el problema. |
| **Offline es una característica** | Si una herramienta necesita un servidor para ser útil, es otro producto. |
| **Una demo es una demo** | Lo experimental se etiqueta. Las releases se prueban, se versionan y se pueden revertir. |
