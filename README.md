## What I Build

I design **local-first AI systems** that run entirely on consumer hardware — no cloud subscriptions, no data leaks, no vendor lock-in. My stack spans from training custom LLM adapters on a GTX 1060 to shipping full-stack multiplayer games with real-time AI agents.

Currently focused on three verticals:
- **🧠 Local AI** — Training, evaluating, and serving custom LLMs on gaming GPUs
- **🎮 Game Development** — Real-time multiplayer with 3D (Three.js) and pixel art canvases
- **🤖 Agent Orchestration** — Coordinating autonomous AI agents for real-world workflows

## Philosophy

| Principle | Practice |
|:---|:---|
| **Local-first** | AI runs on your hardware, not someone else's cloud |
| **Privacy by default** | No telemetry, no data exfiltration, no API keys required for local use |
| **Open-source always** | Every tool I ship is open. Fork it, learn from it, improve it |
| **Consumer hardware** | If it can't run on a GTX 1060, the architecture is wrong |
| **Ship, don't talk** | Working products over polished presentations |
